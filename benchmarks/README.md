# Task 10 benchmark inputs

The three source archives used for Task 10 are stored in this folder:

- `Inspec.zip`
- `kdd.zip`
- `SemEval2017.zip`

Do not extract these ZIPs manually. Run Task 10, step 1 in the main notebook to read them and create processed CSV tables under `data/benchmarks/`, together with the JSONL inputs required for SEKE. Then run Task 10, step 2 to add the four traditional extractor outputs before starting SEKE training.

For details about the dataset sources, see the upstream [INESCTEC KeywordExtractor-Datasets repository](https://github.com/INESCTEC/KeywordExtractor-Datasets).
