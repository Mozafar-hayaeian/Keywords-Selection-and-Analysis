# Benchmark input files

Place the original dataset ZIP archives here without extracting them:

- `Inspec.zip`
- `kdd.zip`
- `SemEval2017.zip`

Task 10 reads each ZIP directly and writes processed CSV files under `data/benchmarks/`. The archive files are not committed here; obtain them from the [INESCTEC KeywordExtractor-Datasets repository](https://github.com/INESCTEC/KeywordExtractor-Datasets) and follow the source's terms of use.
