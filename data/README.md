# Data

`database.csv` is the main PubMed dataset used by the project and is included in this folder.

Task 1 can collect a fresh PubMed sample and overwrite this file. To reproduce the saved results, use the existing snapshot and skip Task 1.

Task 10 creates processed benchmark tables under `data/benchmarks/` when its preparation cell is run. The source archives and their placement are documented only in [benchmarks/README.md](../benchmarks/README.md).
