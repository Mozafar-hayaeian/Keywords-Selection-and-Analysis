# Data

The notebook generates the following files:

- `database.csv`: PubMed records collected by Task 1, then augmented with extracted keyword columns by later tasks.
- `benchmarks/Inspec.csv`, `benchmarks/kdd.csv`, and `benchmarks/SemEval2017.csv`: processed benchmark data generated by Task 10 from the source ZIPs in the top-level `benchmarks/` folder.

These generated files are ignored by Git because they are reproducible outputs and can be large. For exact reproduction of a previous run, use that run's saved data snapshot rather than recollecting PubMed records.
